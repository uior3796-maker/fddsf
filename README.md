# BOX — оружие с модульной кастомизацией

Процедурные 3D-модели оружия для веб-шутера. Каждое оружие — один
самодостаточный HTML-файл: геометрия считается в браузере, внешних ассетов нет.
Навесные модули (прицелы, дульные устройства, фонари, ЛЦУ, рукоятки, сошки,
магазины, приклады, цевья) встроены **внутрь каждого файла оружия** — отдельные
файлы модулей больше не нужны.

## Как пользоваться

Откройте любой файл из `BOX/` в браузере.

| клавиша | действие |
|---|---|
| `Tab` | панель кастомизации |
| `1`…`9` | выбрать слот |
| `←` `→` | перебрать модули в слоте |
| `L` | фонарь |
| `K` | лазер |
| `B` | сошки / складывание приклада |

Из консоли доступен тот же API:

```js
ATTACH.slots()                          // список слотов
ATTACH.options('optic')                 // что можно поставить
ATTACH.set('optic', 'holo_exps3')       // поставить модуль
ATTACH.set('optic', null)               // снять
ATTACH.stats()                          // итоговые характеристики
const code = ATTACH.preset.save()       // сохранить сборку строкой
ATTACH.preset.load(code)                // восстановить
```

## Оружие и слоты

| файл | слоты |
|---|---|
| `ak74.html` | дуло, цевьё, прицел, боковой кронштейн, магазин, приклад |
| `akm.html` | дуло, цевьё, прицел, боковой кронштейн, магазин, приклад |
| `m416.html` | дуло, цевьё, прицел, магазин, приклад |
| `scar-h.html` | дуло, прицел, нижняя планка, боковая планка, магазин, приклад |
| `mp5a3.html` | дуло, цевьё, прицел, магазин, приклад |
| `svd.html` | дуло, сошки, тактика |
| `remington870.html` | дуло, прицел, фонарь |
| `glock18c.html` | дуло, прицел, фонарь |

Цевья с планками (`handguard_mlok`, `handguard_quad`) **сами добавляют новые
слоты** — верхний, нижний и боковые. Они появляются в панели после установки
цевья, на них вешаются фонарь, ЛЦУ, рукоятка или сошки.

## Каталог модулей

**Оптика.** Коллиматор T-2, голографический EXPS3, мини-коллиматор RMR,
прицел 1-6×24, ПСО-1 4×24, магнифер 3×, ночной монокуляр PVS-14, складная
механика BUIS. У каждого — своя высота оптической оси, вынос зрачка, сетка и
поведение камеры при прицеливании.

**Дульные устройства.** Пламегаситель A2, ДТК-компенсатор, линейный
компенсатор, конусный пламегаситель, глушитель QD, дульная гайка. Задают точку
и размер вспышки, направление боковых струй газа, громкость выстрела.

**Тактика.** Фонарь (рефлектор, луч, выносная кнопка), ЛЦУ с видимым и ИК
каналами, комбо-блок, вертикальная и угловая рукоятки, упор кисти, сошки с
раскладыванием, качанием и регулировкой высоты.

**Магазины.** 30 и 45 (АК), STANAG 30, барабан 75, 20 и 25 под 7,62×51,
10 (СВД), пистолетные 17 и 33. Ёмкость и время перезарядки идут в характеристики.

**Приклады и цевья.** Телескопический, складной рамочный, деревянный, заглушка
буферной трубы; цевьё M-LOK, квад-рейл, деревянное.

## Характеристики

Каждый модуль несёт вклад в общие показатели; система складывает их и
пересчитывает в игровые величины с учётом массы сборки: подброс, увод, разброс
от бедра, время вскидки, подвижность, перезарядка, скорость пули, дальность,
громкость, заметность вспышки. Панель показывает стрелками, что улучшилось, а
что ухудшилось после замены.

Система проверяет совместимость: тип слота, калибр магазина, длину посадочного
места, взаимные конфликты. Несовместимая комбинация помечается предупреждением,
а в строгом режиме отклоняется.

## Устройство исходников

```
src/kernel.js              геометрическое ядро (extrude, lathe, loft, …)
src/attach/common.js       общие детали: планка, зажимы, винты, накатка, линзы
src/attach/optics.js       каталог прицелов
src/attach/muzzle.js       каталог дульных устройств
src/attach/tactical.js     фонарь, ЛЦУ, рукоятки, сошки
src/attach/mags_stocks.js  магазины, приклады, цевья, боковые модули
src/attach/system.js       слоты, совместимость, характеристики, пресеты
src/attach/ui.js           панель кастомизации
src/adapters/three_adapter.js  сборка → three.js
src/adapters/raw_adapter.js    сборка → «сырой» WebGL (СВД, Remington, Glock)
src/weapons/slots.js       где у какого оружия слоты и базовая баллистика
```

Единицы — миллиметры. Оси: X вправо, Y вверх, Z назад (дуло смотрит в −Z).
Посадочная точка планочного модуля — центр верхней плоскости планки Пикатинни,
дульного — торец резьбы на оси канала ствола.

## Сборка и проверка

```sh
node tools/build.js         # собрать бандл
node tools/patch_ak74.js    # внедрить в ak74.html
node tools/patch_generic.js # akm, m416, scar-h, mp5a3
node tools/patch_raw.js     # svd, remington870, glock18c
node tools/test.js          # проверки: геометрия, сборки, характеристики
```

Патчеры идемпотентны: код системы живёт между маркерами
`/* ATTACH:BEGIN … */` и `/* ATTACH:END … */`, повторный запуск его заменяет.
Правьте исходники в `src/`, а не сгенерированный блок в HTML.

Стенд для осмотра отдельных модулей: `tools/preview.html`
(`?mode=module&m=reddot_t2` или `?mode=weapon&w=ak74&optic=scope_1_6x`).
