Using the viewer

Drag or use arrow keys to orbit. Scroll, pinch or use + / − to zoom. P toggles power, F flips the mount, R resets. Viewmodel is a close, first-person-style inspection angle.

About the exports

GLB exports the current pose in metres, with separate assembly nodes and a baked procedural PBR atlas. The texture ZIP includes albedo, tangent-space normal, roughness, metallic, AO, emissive and packed ORM maps. Engine shader setup and import validation are still required.

This is an interactive reference, not a production-certified AAA asset. The mesh is triangulated, not a subdivision-ready quad retopology; material bakes are procedural, not a high-poly scan. Glass and studio reflections are approximated on export. 385 g is a design specification, not a simulated mass. Markings are illustrative.
