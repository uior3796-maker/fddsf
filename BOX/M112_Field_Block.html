About this study

A fictional, non-functional game prop. Exterior electronics, wires, labels and the static LCD are visual decoration only. No circuit, working timer or operational simulation is included.

Scale & origin
Nominal wrapper dimensions: 28 × 5 × 2.5 cm. Export origin: centre of the back face, +Z facing outward. GLB units: metres. 570 g is reference metadata, not a physics simulation.
Procedural PBR
Base colour, normal, roughness, metallic, AO and emissive maps. Desktop preview and exports use 4096 × 4096 atlases; compact screens use a lighter 2K preview. AO is procedural, not a ray-traced bake. Normal maps use OpenGL (+Y).
Mesh & handoff
Quad-grid surfaces, triangulated for WebGL and GLB. Padded, non-overlapping UV islands and separate component pivots.
This is a browser-authored study, not a certified AAA production asset. Final LODs, collision, UV/lightmap validation and engine import setup need a production pass. Use a glTF-capable engine importer or Blender as an intermediary; this is not a native Unreal or Unity package.
